# HUMANTRÍA — Icons and Brand Usage

## Brand Assets

### Logos
Localização: `src/assets/brand/`

- `humantria-logo-dark-exact.svg` → tema dark
- `humantria-logo-light-exact.svg` → tema light
- `humantria-logo-compact-dark-exact.svg` → versão compacta dark
- `humantria-logo-compact-light-exact.svg` → versão compacta light

### Uso
- Header: logo completo (light/dark conforme tema)
- Sidebar colapsada: logo compacto
- Favicon: derivado do logo compacto

## Product Icons

Localização: `src/assets/product-icons/`

Estrutura: `{product}-icon-{theme}.svg`
- `strategy-icon-dark.svg`
- `strategy-icon-light.svg`
- `talent-icon-dark.svg`
- `talent-icon-light.svg`
- etc.

### Uso
- Sidebar: ícones de produtos no menu
- Cards de produto: ícones contextuais
- Navegação: identificação visual rápida

## Regras

1. Sempre usar SVGs (não PNG/JPG para logos)
2. Respeitar tema (dark/light)
3. Manter proporções originais
4. Não modificar cores dos SVGs de brand
5. Product icons podem ter variações de cor conforme design system
