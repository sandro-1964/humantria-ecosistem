PROMPT — LOVABLE: HUMANTRÍA PREMIUM UI SYSTEM”

Contexto
Você é o Designer/IA no Lovable para a plataforma HUMANTRÍA.
Objetivo: entregar um Design System premium + UI Shell + padrões de páginas para a plataforma e para cada produto como “app independente”, sem virar BI genérico.

Regras obrigatórias

A plataforma tem UI runtime governado: estados de loading/empty/error/success são parte do sistema.

Toda tela deve ter:

loading state claro (skeleton/spinner)

empty state com orientação (o que fazer agora)

error state com instrução (como resolver)

help contextual (tooltip + “saiba mais”)

Existe um System Inbox (notificações persistentes) + toasts (rápidos).

Existe /__diag (diagnóstico visual mínimo) e uma página Meta (“fingerprint”, versão, ambiente).

Plataforma ≠ BI: dashboards são Decision Dashboards (topo executivo, evidência e narrativa), com qualidade gráfica premium, sem “cara de BI barato”.

Entregas
A) Design System (premium)

Tokens: tipografia, espaçamentos, grid, radius, sombras, estados (hover/focus/disabled), componentes

Componentes base: buttons, inputs, selects, tables, cards, modals, drawers, tabs, breadcrumbs, badges, toasts, notifications, empty states, skeletons

Padrões: lista → detalhe → formulário; wizard; search; filtros; bulk actions

B) UI Shell da Plataforma

Header, Sidebar, Footer, layout responsivo (desktop-first + tablet + smartphone)

Navegação: “Home Humantría (mapa)” + módulos contratados

Páginas do Foundation (admin):

Tenant Admin: Users & Roles, Settings (locale/timezone/currency), Privacy/LGPD (registro), AI Settings (se habilitado), Sandbox/Demo/Trial status

Platform Owner Console: Tenants, Plans/Packaging, Templates, Health/Incidents, Audit, Flags/Quotas, Usage/Costs

C) Padrões de produto (apps independentes)
Cada produto terá:

Página do produto (in-app home)

Landing page do produto (marketing)

3 páginas padrão: Overview (decisão), Worklist (pendências), Detail (decisão/evidência)

Produtos a contemplar no design (sumário de navegação):

Strategy, Talent, Workforce Ops, GRC, Intelligence, Experience, Evolution, Chronos
(Orchestra fica fora por enquanto.)

D) Landing page da Plataforma
Criar landing da plataforma conectada ao Foundation (narrativa + confiança + governança + decisão + evidência), com seção para produtos/SKUs.

Tom e microcopy

Mensagens devem seguir: [O que aconteceu] + [Por quê] + [O que fazer agora]

Evitar jargão técnico.

Saída esperada

Um projeto Lovable com: Design System + UI Shell + páginas base do Foundation/Core + “starter kit” visual de cada produto + landing pages (plataforma e produtos).
